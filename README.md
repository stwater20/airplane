# ✈️ 桃園 → 成田 飛行模擬器

瀏覽器上的 3D 飛行模擬遊戲（Three.js），從 **臺灣桃園國際機場 (RCTP) 05R** 起飛，沿琉球群島與日本南岸飛往 **東京成田國際機場 (RJAA) 34L**。

**線上遊玩：** https://airplane.sectools.tw/

## 輕鬆模式（預設，手機可玩）

- 自動起飛、自動巡航、自動降落，**不會墜機**
- 按住螢幕任意處拖曳（或方向鍵）：左右＝轉彎、上下＝爬升／下降
- 穿過金色圓環 +100 分，降落越平穩加分越多
- 巡航會自動快轉，也可以按「⏩ 跳到降落」

## 專業模式特色

- 真實比例地理：臺灣、琉球、九州、四國、本州（含富士山、玉山等山脈），約 1,180 NM 航程
- 簡化物理飛行模型（升力／阻力／推力／失速、地面滾行、襟翼、起落架、減速板）
- 類 Airbus 線傳飛控：放開搖桿時保持航跡與坡度
- 自動駕駛：HDG / NAV（沿航路）/ ALT / 自動油門（含 M0.80 限制）
- ILS 34L 進場：LOC、G/S 截獲、自動拉平與自動降落
- PFD（姿態儀、速度帶、高度帶、升降速度、羅盤、ILS 偏差）、航圖、FMA
- 4 種視角：追蹤、駕駛艙、自由環繞、塔台
- 時間加速最高 x64（3000 ft 以下限制 x4）
- 落地評分（接地垂直速度）、各種墜機判定

## 操作

| 功能 | 按鍵 |
| --- | --- |
| 俯仰（推／拉） | `W` `S` / `↑` `↓` |
| 滾轉 | `A` `D` / `←` `→` |
| 方向舵／前輪轉向 | `Q` `E` |
| 油門 + / − | `R` `F`（或 Shift / Ctrl） |
| 襟翼 收 / 放 | `Z` `X` |
| 起落架 | `G` |
| 煞車（按住 / 切換） | `Space` / `B` |
| 減速板 | `H` |
| 自動駕駛 / 自動油門 | `K` / `U` |
| 航路導航 / ILS 進場待命 | `N` / `L` |
| 時間加速 + / − | `T` / `Y` |
| 切換視角 / 地圖縮放 | `C` / `M` |
| 暫停 | `P` / `Esc` |

## 建議飛法

1. 按住 `R` 油門 100%，約 150 kt 時按住 `S` 抬頭至 10°。
2. 離地後 `G` 收起落架、`Z` 收襟翼。
3. 400 ft 以上按 `K` `U` `N`：自動駕駛會沿航路爬升到 FL350。
4. 巡航中 `T` 加速時間。到房總半島 (BOSO) 前把 ALT 設 3000、SPD 設 180。
5. 按 `L` 待命進場，放襟翼與起落架，飛機會截獲 ILS 並自動降落；落地後停在跑道上即完成。

## 本機執行

純靜態網站，無需建置：

```bash
python3 -m http.server 8000
```

然後開啟 http://localhost:8000 。

> 地形與海岸線為手繪簡化資料，僅供娛樂，不可用於真實飛航。
